# 跨子系统多跳故障诊断与工程排障实战案例集

## 案例一：润滑系统退化引发滚动轴承外圈早期剥落

某车间 3 号离心泵机组运行过程中，InfluxDB 时序数据库记录到驱动端温度传感器读数在 48 小时内缓慢上升 14℃，边缘采集网关运行的孤立森林模型率先发出早期异常预警，但此时传统 FFT 频谱分析中的 1倍频与 2倍频幅值均仍在 ISO 20816 振动标准的 B 区内。

运维团队随即调用包络解调分析高频振动波形，发现高频冲击脉冲能量显著增强并出现清晰的特征频率 BPFO。通过 GraphRAG 根因推理串联“润滑脂劣化 → 轴承温升异常 + 高频冲击脉冲 → 滚动轴承外圈剥落 → 轴承润滑与更换 SOP”多跳因果链，现场在计划停机窗口执行轴承润滑与更换 SOP，拆检确认油脂干涸且外圈存在早期微剥落，成功避免了一次非计划停机事故。

## 案例二：联轴器轴系不对中诱发电机电流与轴承连锁异常

某重型齿轮箱驱动端出现持续的 2倍频振动升高，同时三相异步电机电流互感器监测到周期性的电机定子电流波动，且伴随驱动端滚动轴承温升异常。传统单指标阈值告警同时触发了“电机故障”与“轴承过热”两条孤立告警，现场难以判断优先排查对象。

引入 GraphRAG 根因推理后，系统综合多源症状命中“轴系不对中”核心根因：轴系不对中经由弹性联轴器产生附加轴向载荷，一方面加剧滚动轴承摩擦温升，另一方面传导至三相异步电机引起电机定子电流波动。现场依据推荐的激光对中 SOP 检查发现电机地脚存在软脚并重新完成激光对中，复机后 2倍频振动升高与电流波动同步消除。

## 案例三：边缘采集网关采样率配置漂移导致的虚假故障告警

一次 Docker 容器平台例行版本更新后，多个正常运行的离心泵机组突然集中上报高频异常与疑似轴承特征频率告警。模型漂移监控发现新版本上线后边缘侧特征分布 PSI 骤升，但现场便携仪复测振动烈度完全处于 ISO 20816 A 区。

进一步排查发现，新版边缘采集网关配置文件错误地将振动加速度传感器采样率从 12.8 kHz 降为 2 kHz 且未同步调整低通截止频率，导致高频背景噪声折叠进低频带产生频谱混叠失真，误导了 ONNX Runtime 中的孤立森林模型。运维人员立即执行边缘配置回滚 SOP，恢复正确采样参数与抗混叠配置，并在发布流水线中补充了采样率与量纲一致性自动校验门禁。
